# Complete Working Flow & Guides

## Admin Guide
- **Step 1:** Open `Admin_App.exe`.
- **Step 2:** Auto-login to Admin Dashboard (Email: admin.mobile.servicemaster@gmail.com).
- **Step 3:** Monitor Live Users via `/api/admin/live-users`.
- **Step 4:** Manage B2B Integrations (UnlockTool, Chimera) and check system limits.

## User Guide
- **Step 1:** Open `Client_App.exe`.
- **Step 2:** Register/Login using OTP.
- **Step 3:** Search your mobile model (12,000+ available).
- **Step 4:** Request unlock/service. Track live status and chat with AI Assistant.

## Local & International Flow
- **Local:** Utilizes LAN IP (e.g., 192.168.x.x:5000) for local team (5-10 users).
- **International:** Deployed on Render (Singapore Region). Uses Gunicorn for production and Firebase/Supabase for Cloud Sync.
